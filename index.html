The pickers

  • Overwatch Hero Picker owheropicker.com

    • Discord server for the Overwatch Hero Picker
    • GitHub source for the Overwatch Hero Picker

    Tick the heroes you're happy to play, or a whole role, and let it choose. Good for warming up, for getting out of a one-trick rut, or for running your own Mystery Heroes.

    • Filter by hero or by role
    • Squad Generator for full team comps
    • Randomize perks along with the hero
    • Save presets, share a roll with a link

  • Valorant Agent Picker valorantpicker.com

    • Discord server for the Valorant Agent Picker
    • GitHub source for the Valorant Agent Picker

    Narrow the pool to the agents you know, or the ones you're trying to learn, and get one at random instead of staring at the agent select clock.

    • Filter by agent or by role
    • Squad Generator for a full five-stack
    • Save presets for your comfort picks
    • Share a roll or a squad with a link
